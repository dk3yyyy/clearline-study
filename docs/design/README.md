# ShiftReady design package (light + dark)

Start here:
1. Open `reference/index.html` (landing page) and `reference/app-screens.html` (phone screens) in a browser.
   Use the sun/moon button to switch between dark and light mode.
2. Give your AI agent this whole folder and tell it:
   "Follow DESIGN-AGENT-INSTRUCTIONS.md for the design and docs/SIA-STUDY-SITE-AGENT-INSTRUCTIONS.md for the content and build."

Folders:
- reference/      Working HTML/CSS reference. theme.css holds all colours and fonts for both themes.
- design-source/  Original design-canvas files (reference only; they need the canvas runtime to render).
- docs/           Full site and question-bank build instructions.
